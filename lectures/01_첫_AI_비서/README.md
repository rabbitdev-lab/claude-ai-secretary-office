# 특강 1: 코딩 몰라도 만드는 첫 AI 비서

회의 녹취록을 넣으면 정해진 양식으로 회의록을 써 주는 스킬을 만들어 테스트하고 고칩니다. 책 Part 01과 같은 내용입니다. 준비물은 [lectures 안내](../README.md)를 먼저 봐 주세요.

## 준비

1. 예제 파일을 내려받아 압축을 풉니다.
2. 클로드 데스크톱 앱 → Code 탭 → 작업 폴더로 `claude-ai-secretary-office-main/lectures/01_첫_AI_비서/ai-secretary` 폴더를 고릅니다. **맨 위 폴더를 고르면 책의 다른 스킬이 섞이니** 꼭 `ai-secretary` 폴더를 고르세요.
3. skill-creator(스킬을 만들어 주는 스킬)를 설치해 둡니다 (책 실습 04). 설치한 뒤에는 클로드 앱을 다시 시작해야 목록에 보입니다.

`transcripts`(녹취록 폴더)에 가상 회사 정산메이트의 회의 녹취록 3개가 들어 있습니다.

| 녹취록 | 용도 |
|---|---|
| `2026-11-24_팀승인기능_기획회의_녹취.txt` | 결정 사항과 담당자가 분명한 회의. 스킬을 처음 실행할 때 씁니다 |
| `2026-11-25_주간싱크_녹취.txt` | 담당자가 정해지지 않은 할 일이 있는 회의. 클로드가 담당자를 지어내지 않는지 봅니다 |
| `2026-11-26_신규채용_논의_녹취.txt` | 결정 사항이 없는 회의. 스킬이 결정을 지어내지 않는지 확인할 때 씁니다 |

## 따라 하기

아래 문장을 복사해서 클로드에게 그대로 입력하면 됩니다.

**1. CLAUDE.md(클로드가 매번 먼저 읽는 안내 파일) 만들기**

```
이 폴더에 CLAUDE.md를 만들어 줘. 나는 정산메이트라는 경비 정산 서비스 회사의 PM이야. 결과는 한국어로 쓰고, 새로 만드는 파일 이름은 날짜로 시작해 줘.
```

**2. 회의록 스킬 만들기**

```
skill-creator로 스킬을 만들어 줘. 회의 녹취록을 받으면 회의록으로 정리하는 스킬이야. 녹취록은 transcripts 폴더에 있어. 결과는 참석자, 결정 사항, 할 일 순서로 쓰고, 할 일에는 담당자와 기한을 붙여 줘. 담당자나 기한이 없으면 따로 표시해 줘. 정리한 회의록은 meetings 폴더에 저장하고, 파일 이름은 회의 날짜와 회의 이름으로 정해 줘.
```

skill-creator가 없다면 첫 문장을 "이 폴더의 .claude/skills 폴더에 회의록 정리 스킬을 만들어 줘."로 바꿔서 입력합니다.

만들어진 스킬 파일(SKILL.md)은 "방금 만든 SKILL.md 열어서 보여 줘"라고 하면 볼 수 있습니다. 내용을 읽어 본 뒤 "팀 승인 기능 기획 회의 녹취록 정리해 줘"라고 실행합니다. 결과는 `meetings`(회의록 폴더)에 저장됩니다. 마음에 드는 결과가 나오면 "이 결과를 스킬의 예시로 넣어 줘"라고 요청합니다.

**3. 스킬 이름 없이 요청해도 스킬이 쓰이는지 확인하기**

새 대화를 열고 입력합니다.

```
주간 싱크 회의 녹취록 좀 정리해 줘.
```

스킬이 쓰이지 않으면 description(스킬 설명. 언제 쓰는 스킬인지 적는 칸)을 고칩니다.

```
회의록 스킬의 description에 "회의 정리", "녹취록 요약", "회의 내용 정리" 같은 표현도 넣어 줘. 이런 말로 요청할 때도 이 스킬을 쓰게 해 줘.
```

**4. 까다로운 녹취록으로 테스트하고 규칙 고치기**

채용 논의 녹취록으로도 실행해 본 뒤 입력합니다.

```
담당자가 없는 할 일은 맨 아래 "담당자 정해야 할 일"로 따로 모아 줘. 결정 사항이 없는 회의는 비워 두지 말고 "결정 사항 없음"이라고 써 줘. 이 내용을 스킬에 반영해 줘.
```

## 내 업무에 쓰기

빈칸만 내 업무로 바꿔서 skill-creator에게 입력합니다.

```
skill-creator로 스킬을 만들어 줘.
[언제] ______할 때 쓰는 스킬이야.
[입력] ______ 폴더에 있는 ______을 읽어.
[순서] 1) ______ 2) ______ 3) ______
[결과] ______ 모양으로 써서 ______ 폴더에 저장해.
[예외] ______이 없거나 애매하면 지어내지 말고 나에게 물어봐.
```
