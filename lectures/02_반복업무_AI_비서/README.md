# 특강 2: 출근부터 퇴근까지, 반복 업무를 AI 비서에게 넘기기

아침 메일 브리핑, 답장 초안, 회의록, 퇴근 전 하루 정리를 하루 순서대로 클로드에게 맡깁니다. 책 Part 02와 같은 내용입니다.

## 준비

1. **연습용 구글 계정**을 준비합니다. 평소 쓰는 계정이나 회사 계정은 쓰지 않습니다.
2. 연습용 계정에 메일과 일정을 넣습니다. [`gmail_seed.gs`](gmail_seed.gs) 맨 위 설명대로 script.google.com에서 `seedDemo`를 실행하면 가상 메일 16통과 일정 6개가 들어갑니다. 어떤 메일인지는 [`메일_목록.md`](메일_목록.md)에 있습니다. 메일 본문과 일정은 2026년 12월 4일(금)을 오늘로 보고 쓰여 있습니다.
3. 클로드 데스크톱 앱 → 설정 → 커넥터에서 연습용 계정의 Gmail과 Google Calendar를 연결합니다 (책 실습 11).
4. `ai-secretary` 폴더를 복사해 Code 탭 작업 폴더로 고릅니다. 특강 1에서 만든 회의록 스킬(`.claude/skills/meeting-notes`)과 CLAUDE.md, 회의 녹취록이 들어 있습니다.

## 따라 하기

**1. 아침 메일 브리핑 스킬**

```
skill-creator로 아침 메일 브리핑 스킬을 만들어 줘. 지난 24시간 동안 받은 메일을 읽고 오늘 답할 메일, 확인할 메일, 읽어만 둘 메일, 광고로 나눠 줘. 답할 메일은 보낸 사람, 요청 내용, 기한을 한 줄씩 쓰고 급한 것부터 정렬해 줘. 메일은 보내거나 지우지 마.
```

만든 뒤 새 대화에서 "오늘 메일 브리핑해 줘"라고 요청합니다.

**2. 메일 속 일정과 캘린더 대조**

```
이번 주 메일에서 회의 요청과 마감을 뽑아서 내 캘린더 일정과 겹치는지 확인해 줘.
```

**3. 답장 초안 스킬**

```
skill-creator로 답장 초안 스킬을 만들어 줘. 문의 메일에 정중한 존댓말로 답장 초안을 써서 지메일 초안함에 넣어 줘. 확인이 필요한 내용은 [확인 필요]로 표시하고, 일정이나 보상은 약속하지 마. 영어 메일에는 영어로 답장해.
```

스킬을 만들고 나서 "그린리프 이수진 님 메일이랑 FinTrail 영문 메일에 답장 초안 써 줘"라고 요청합니다. 지메일 초안함에서 초안을 확인합니다. 보내기 버튼은 직접 누릅니다.

**4. 회의록과 담당자별 메시지 초안**

```
12월 4일 주간 리뷰 녹취록을 회의록으로 정리해 줘.
```

```
회의록에서 담당자별로 할 일을 묶어서 각자에게 보낼 짧은 메시지 초안을 써 줘. 보내지는 말고 화면에만 보여 줘.
```

**5. 하루 마무리**

책 저장소의 [`skills/daily-summary`](../../skills/daily-summary/)를 참고하거나 skill-creator로 하루 마무리 스킬을 만든 뒤 "오늘 하루 마무리해 줘"라고 요청합니다.

## 다 쓴 뒤

연습용 계정의 script.google.com에서 `cleanupDemo`를 실행하면 스크립트가 넣었던 메일과 일정을 지웁니다.

## 책 저장소의 완성 스킬

비슷한 스킬이 이 저장소의 `skills` 폴더에 완성본으로 있습니다. `email-briefing`, `email-draft-replies`, `meeting-summary`, `daily-summary`를 받아서 바로 쓰거나 고쳐 써 보세요.
