# 특강 2: 출근부터 퇴근까지, 반복 업무를 AI 비서에게 넘기기

아침 메일 브리핑, 답장 초안, 회의록, 퇴근 전 하루 정리를 하루 순서대로 클로드에게 맡깁니다. 책 Part 02와 같은 내용입니다. 준비물은 [lectures 안내](../README.md)를 먼저 봐 주세요.

특강에서는 지메일을 연결해서 시연하지만 **지메일 없이 연습용 메일 파일로 똑같이 따라 할 수 있습니다.** 아래 기본 과정은 구글 계정이 없어도 됩니다.

## 기본 과정: 메일 파일로 따라 하기

### 준비

1. 예제 파일을 내려받아 압축을 풉니다.
2. 클로드 데스크톱 앱 → Code 탭 → 작업 폴더로 `claude-ai-secretary-office-main/lectures/02_반복업무_AI_비서/ai-secretary` 폴더를 고릅니다.

이 폴더에 들어 있는 것입니다. 모두 가상 회사 정산메이트의 PM 박현진이 받은 메일과 일정이라는 설정입니다. 2026년 12월 4일(금)을 오늘로 보고 만들었습니다.

| 폴더·파일 | 내용 |
|---|---|
| `메일` | 받은 메일 16통 (고객 문의, 상사 요청, 영문 메일, 팀원 주간 보고, 광고 등) |
| `일정.md` | 내 캘린더 일정 |
| `transcripts` | 12월 4일 주간 리뷰 회의 녹취록 |
| `.claude/skills/meeting-notes` | 특강 1에서 만든 회의록 스킬 |
| `CLAUDE.md` | 클로드가 매번 먼저 읽는 안내 파일 |
| `답장초안`, `meetings`, `daily` | 결과가 저장될 빈 폴더 |

### 따라 하기

**1. 아침 메일 브리핑 스킬**

```
skill-creator로 아침 메일 브리핑 스킬을 만들어 줘. 메일 폴더에 있는 메일을 읽고 오늘 답할 메일, 확인할 메일, 읽어만 둘 메일, 광고로 나눠 줘. 답할 메일은 보낸 사람, 요청 내용, 기한을 한 줄씩 쓰고 급한 것부터 정렬해 줘. 메일 파일은 고치거나 지우지 마.
```

만든 뒤 새 대화에서 "오늘 메일 브리핑해 줘"라고 요청합니다. 결과를 보고 메일 파일 한두 개를 직접 열어 맞게 정리했는지 확인해 보세요.

**2. 메일 속 일정과 내 일정 대조**

```
메일 폴더의 메일에서 회의 요청과 마감을 뽑아서 일정.md에 적힌 내 일정과 겹치는지 확인해 줘.
```

**3. 답장 초안 스킬**

```
skill-creator로 답장 초안 스킬을 만들어 줘. 문의 메일에 정중한 존댓말로 답장 초안을 써서 답장초안 폴더에 저장해 줘. 확인이 필요한 내용은 [확인 필요]로 표시하고, 일정이나 보상은 약속하지 마. 영어 메일에는 영어로 답장해.
```

스킬을 만들고 나서 "그린리프 이수진 님 메일이랑 FinTrail 영문 메일에 답장 초안 써 줘"라고 요청합니다.

**4. 회의록과 담당자별 메시지 초안**

```
12월 4일 주간 리뷰 녹취록을 회의록으로 정리해 줘.
```

```
회의록에서 담당자별로 할 일을 묶어서 각자에게 보낼 짧은 메시지 초안을 써 줘. 보내지는 말고 화면에만 보여 줘.
```

**5. 하루 마무리**

```
오늘 하루 정리해 줘. 메일 폴더에서 아직 답하지 않은 메일, 답장초안 폴더의 초안, meetings 폴더의 오늘 회의록, 일정.md의 내일 일정을 모아서 daily 폴더에 저장해 줘.
```

## 선택 과정: 지메일로 해 보기

실제 받은편지함으로 해 보고 싶은 분만 하세요. 단계가 많습니다. **평소 쓰는 계정이나 회사 계정은 쓰지 않습니다.**

1. 연습용 구글 계정을 새로 만듭니다.
2. 연습용 계정으로 [script.google.com](https://script.google.com)에 들어가 새 프로젝트를 만든 뒤 [`gmail_seed.gs`](gmail_seed.gs) 내용을 붙여 넣습니다. 파일 맨 위의 설명대로 Gmail API(프로그램끼리 정보를 주고받는 창구)를 추가하고 `seedDemo`를 실행하면 같은 메일 16통과 일정 6개가 들어갑니다.
3. 처음 실행하면 **"Google에서 확인하지 않은 앱"이라는 경고**가 나옵니다. 내가 붙여 넣은 스크립트라서 나오는 정상 화면입니다. "고급" → "(안전하지 않음)으로 이동" → "허용"을 누릅니다.
4. 메일 받은 시각이 스크립트를 실행한 시각 기준으로 찍히니, **스크립트를 실행한 직후에** 따라 하세요. 하루가 지나면 "지난 24시간" 브리핑에 메일이 잡히지 않습니다.
5. 클로드 데스크톱 앱 → 설정 → 커넥터(지메일 같은 서비스를 클로드에 연결하는 기능)에서 연습용 계정의 Gmail과 Google Calendar를 연결합니다 (책 실습 11).
6. 기본 과정의 요청 문장에서 "메일 폴더"를 "지난 24시간 동안 받은 메일"로, "답장초안 폴더"를 "지메일 초안함"으로, "일정.md"를 "내 캘린더"로 바꿔서 입력합니다.
7. 다 쓴 뒤에는 script.google.com에서 `cleanupDemo`를 실행하면 스크립트가 넣었던 메일과 일정을 지웁니다.

어떤 메일인지는 [`메일_목록.md`](메일_목록.md)에 정리해 두었습니다.
