# 회의록 정리

transcripts 폴더의 녹취록을 읽고 회의록을 만든다.

## 순서

1. 회의 이름, 일시, 참석자를 적는다
2. 결정 사항을 묶는다
3. 할 일에 담당자와 기한을 붙인다. "이번 주 금요일"처럼 상대적인 날짜는 회의 날짜를 기준으로 실제 날짜로 바꾼다
4. meetings 폴더에 `날짜_회의명.md`로 저장한다

## 주의

- 녹취록에 없는 내용은 지어내지 않는다
- 담당자가 없는 할 일은 맨 아래 "담당자 정해야 할 일"로 따로 모은다
- 결정 사항이 없으면 "결정 사항 없음"이라고 쓴다
- 녹취록 원본은 고치지 않는다

## 결과 예시

```
# 팀 승인 기능 기획 회의 (2026-11-24)

참석: 박현진, 김민지, 이재호, 최서연

## 결정 사항
- 1차 범위: 목록 보기, 일괄 승인, 반려 사유 입력

## 할 일
- 김민지: 모바일 목록 시안 (11/27 금)

## 담당자 정해야 할 일
- 없음
```
