## 따라 하려면 미리 준비해 주세요

- **클로드 데스크톱 앱**을 설치하고 로그인합니다. [claude.ai/download](https://claude.ai/download)
- **Pro 또는 Max 구독**이 필요합니다. 내 폴더의 파일을 다루는 Code 탭(클로드가 내 폴더의 파일을 직접 다루는 화면)은 유료 플랜에서 쓸 수 있습니다.
- **개인 PC**에서 하시길 권합니다. 회사 PC는 프로그램 설치나 결제가 막혀 있을 수 있습니다.
- **예제 파일**은 아래 링크를 누르면 ZIP 파일로 바로 내려받아집니다. 내려받은 파일을 압축 풀기 하면 `claude-ai-secretary-office-main` 폴더가 생깁니다.
  - [예제 파일 내려받기 (ZIP)](https://github.com/rabbitdev-lab/claude-ai-secretary-office/archive/refs/heads/main.zip)
  - 맥: 내려받은 ZIP 파일을 더블클릭합니다
  - 윈도우: ZIP 파일을 마우스 오른쪽 버튼으로 누르고 "압축 풀기"를 고릅니다

## 처음이라면 알아 두면 좋은 것

- **작업 폴더**는 클로드에게 맡기는 폴더입니다. 동료에게 서류철을 건네듯 폴더를 고르면, 클로드는 그 안의 파일만 읽고 씁니다.
- **.md 파일**은 메모장으로 열리는 글 파일입니다. 제목과 목록을 기호(#, -)로 표시합니다.
- 클로드는 파일을 만들거나 고치기 전에 **허용할지 묻습니다.** 내용을 확인하고 "허용"을 누르면 됩니다.
- 점(.)으로 시작하는 폴더(예: `.claude`)는 숨겨져 있습니다. 맥 Finder에서는 Cmd+Shift+. 을 누르면 보입니다. 윈도우 파일 탐색기에서는 보기 → 숨긴 항목을 체크합니다.

## 예제 파일에 대해

등장하는 회사와 인물(정산메이트, 박현진 등)은 모두 책과 특강을 위해 만든 가상 설정입니다. 메일 주소는 실제로 없는 `.example` 도메인을 썼습니다.
