## 준비물

- 클로드 데스크톱 앱 (내 폴더의 파일을 읽고 쓰는 Code 탭은 Pro 또는 Max 구독에서 쓸 수 있습니다)
- 이 저장소 (오른쪽 위 Code → Download ZIP으로 받아 압축을 풉니다)
- 옵시디언 앱 (특강 3)

## 예제 파일에 대해

등장하는 회사와 인물(정산메이트, 박현진 등)은 모두 책과 특강을 위해 만든 가상 설정입니다. 메일 주소는 실제로 없는 `.example` 도메인을 썼습니다.
