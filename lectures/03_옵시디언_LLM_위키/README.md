# 특강 3: 쓸수록 똑똑해지는 업무 지식 창고, 옵시디언 x LLM 위키

흩어진 메모를 주제별 지식 카드로 엮고 쌓인 기록에서 결정 사항을 찾아 주간 보고서로 만듭니다. 책 Part 04와 같은 내용입니다.

이 특강에는 따로 예제 파일이 없습니다. **이 저장소 전체를 옵시디언 보관소로 열어서 씁니다.** 저장소에 `notes`(메모 42개), `daily`(데일리 노트 5개), `meetings`(회의록)와 필요한 스킬이 이미 들어 있습니다.

## 준비

1. 저장소를 ZIP으로 받아 압축을 풉니다.
2. 옵시디언에서 "폴더를 보관소로 열기"로 압축을 푼 폴더를 엽니다.
3. 클로드 데스크톱 앱 → Code 탭에서 같은 폴더를 작업 폴더로 고릅니다.
4. 저장소의 `skills` 폴더에서 아래 스킬 3개를 작업 폴더의 `.claude/skills/`로 복사합니다.
   - `obsidian-knowledge-card` (지식 카드 만들기와 점검)
   - `obsidian-recall` (기록·결정 찾기)
   - `weekly-work-report` (주간업무보고)

평소 쓰는 옵시디언 보관소에서 바로 실행하지 말고 이 연습용 보관소에서 먼저 해 보세요.

## 따라 하기

**1. 지식 카드 만들기**

```
notes 폴더 메모로 지식 카드 만들어 줘.
```

클로드가 카드 6장을 만들고 메모가 하나뿐인 주제는 건너뜁니다. 카드의 출처 링크를 눌러 원본 메모와 대조해 보세요.

**2. 스킬을 내 방식대로 고쳐 쓰기**

```
메모가 하나뿐이라 건너뛴 주제들은 "기타" 카드 한 장에 모아 줘. 이 내용을 스킬에 반영해 줘.
```

**3. 카드 점검**

```
카드와 메모가 어긋난 곳이 있는지 점검해 줘.
```

**4. 기록과 결정 찾기**

```
앱인 캠페인 관련 기록이랑 결정 찾아 줘.
```

**5. 주간업무보고**

```
4월 20일부터 24일까지 쓴 데일리 노트로 주간업무보고 만들어 줘. 워드 파일 대신 옵시디언에서 볼 수 있게 마크다운 표로 weekly 폴더에 저장해 줘. 이 저장 방식을 스킬에 반영해 줘.
```

`weekly-work-report` 스킬은 원래 워드 파일을 만듭니다. 회사에 워드로 내야 하면 첫 문장만 입력하면 됩니다.

## 참고

LLM 위키는 AI 연구자 안드레이 카파시가 2026년 4월 깃허브 gist로 공개한 제안입니다. 책 Part 04의 「더 깊이」 코너에도 소개되어 있습니다.
