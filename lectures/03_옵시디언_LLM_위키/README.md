# 특강 3: 쓸수록 똑똑해지는 업무 지식 창고, 옵시디언 x LLM 위키

흩어진 메모를 주제별 지식 카드로 엮고 쌓인 기록에서 결정 사항을 찾아 주간 보고서로 만듭니다. 책 Part 04와 같은 내용입니다. 준비물은 [lectures 안내](../README.md)를 먼저 봐 주세요.

이 특강에는 따로 예제 파일이 없습니다. **내려받은 저장소 폴더 전체를 그대로 씁니다.** 저장소에 `notes`(메모 42개), `daily`(데일리 노트 5개), `meetings`(회의록)와 필요한 스킬이 이미 들어 있습니다. 폴더가 많아 보여도 오늘은 `notes`, `daily`, `meetings`만 봅니다.

## 옵시디언은 있으면 좋고, 없어도 됩니다

지식 카드, 결정 찾기, 주간 보고는 클로드만으로 됩니다. 옵시디언은 결과를 보기 편하게 해 주는 메모 앱입니다. 옵시디언이 없으면 클로드에게 "만든 카드 열어서 보여 줘"라고 하면 됩니다. 옵시디언을 쓰면 카드 속 링크를 눌러 원본 메모로 바로 가거나 메모끼리 연결된 모습을 그래프로 볼 수 있습니다.

## 준비

1. 예제 파일을 내려받아 압축을 풉니다. `claude-ai-secretary-office-main` 폴더가 생깁니다.
2. (옵시디언을 쓴다면) 옵시디언([obsidian.md](https://obsidian.md))을 설치하고 "폴더를 보관소로 열기"로 이 폴더를 엽니다. 보관소는 옵시디언이 메모를 모아 두는 폴더를 말합니다.
3. 클로드 데스크톱 앱 → Code 탭에서 같은 폴더를 작업 폴더로 고릅니다.
4. 클로드에게 아래 문장을 입력해서 책 스킬을 쓸 수 있게 합니다. 저장소의 CLAUDE.md(클로드가 매번 먼저 읽는 안내 파일)에 스킬 폴더를 연결하는 방법이 적혀 있어서 이 한 문장이면 됩니다.

```
CLAUDE.md에 적힌 대로 .claude/skills 링크를 만들어 줘.
```

평소 쓰는 메모 폴더에서 바로 실행하지 말고 이 연습용 폴더에서 먼저 해 보세요.

## 따라 하기

**1. 지식 카드 만들기**

```
notes 폴더 메모로 지식 카드 만들어 줘.
```

클로드가 `cards`(지식 카드 폴더)에 카드 6장 정도를 만들고 메모가 하나뿐인 주제는 건너뜁니다. 결과는 조금씩 다를 수 있습니다. 카드의 출처 링크를 눌러 원본 메모와 대조해 보세요.

**2. 스킬을 내 방식대로 고쳐 쓰기**

```
메모가 하나뿐이라 건너뛴 주제들은 "기타" 카드 한 장에 모아 줘. 이 내용을 스킬에 반영해 줘.
```

**3. 카드 점검**

```
카드와 메모가 어긋난 곳이 있는지 점검해 줘.
```

**4. 기록과 결정 찾기**

```
앱인 캠페인 관련 기록이랑 결정 찾아 줘.
```

**5. 주간업무보고**

```
4월 20일부터 24일까지 쓴 데일리 노트로 주간업무보고 만들어 줘. 워드 파일 대신 옵시디언에서 볼 수 있게 마크다운 표로 weekly 폴더에 저장해 줘. 이 저장 방식을 스킬에 반영해 줘.
```

주간 보고 스킬은 원래 워드 파일을 만듭니다. 회사에 워드로 내야 하면 첫 문장만 입력하면 됩니다. 옵시디언이 없다면 "만든 주간업무보고 보여 줘"라고 하면 됩니다.

## 참고

LLM 위키는 AI 연구자 안드레이 카파시가 2026년 4월 gist(깃허브의 짧은 글 공유 공간)로 공개한 제안입니다. LLM은 클로드, ChatGPT 같은 대화형 AI를 말합니다. 책 Part 04의 「더 깊이」 코너에도 소개되어 있습니다.
